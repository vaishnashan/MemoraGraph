    and activate venv

 uvicorn application.ingestion.main:app --reload

2.To run mcp
  python -m application.mcp.server

  npx @modelcontextprotocol/inspector python -m application.mcp.server


3.docker

docker compose up --build
    
This one starts automatically with plain docker compose up --build since it has no profiles: set. Just open:
http://localhost:8000/docs
Check docker compose logs -f memoragraph-ingestion if you want to watch it load.


starting the container yourself and let Inspector spawn it directly via docker compose run:
  npx @modelcontextprotocol/inspector docker compose run -T --rm memoragraph-mcp python -m application.mcp.server
